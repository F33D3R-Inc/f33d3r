Publish from OBS or another encoder

{{if .Revealed}}

Paste these into OBS under Settings → Stream → Service: Custom…, then press Start Streaming. Your broadcast turns live the moment frames arrive.

This key is shown once and is not stored anywhere it can be read back. Copy it now. Anyone holding it can broadcast as you until you reveal a new one.

{{if .HostIsLocal}}

These URLs point at {{.PublicHost}}, which only resolves on the machine running f33d3r. An encoder on a phone or a second computer cannot reach it. To publish from another device, set LIVE_PUBLIC_HOST to this machine's LAN address and restart the stack, then reveal the key again.

{{else}}

Your encoder must be able to reach {{.PublicHost}} on TCP 1935 (RTMP) or UDP 8890 (SRT).

{{end}}

{{else}}

OBS, a hardware encoder or a phone encoder app publishes into this broadcast with a server URL and a stream key. The key is a publish credential, so it is shown only to you, only here, and only when you ask for it.

Revealing mints a new key and retires the previous one immediately. If an encoder is already configured for this broadcast, it will need the new key to reconnect.

{{end}}
