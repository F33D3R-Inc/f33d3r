Dev tools

These tools affect live data. Use with care. All actions are logged to the PIAL audit trail.

{{/* Inject AET */}}
Inject AET balance

Credit AET tokens to any user's wallet via Ain Soph.

{{/* Reset password */}}
Reset password

Directly set a new password for an account.

{{/* Set email */}}
Set email address

Set or correct a user's email (enables password recovery).

{{/* Resync follow counts */}}
Resync follower / following counts

Recomputes every user's follower and following count directly from the follows table. Run this if the displayed counts don't match what's shown in the followers/following lists (caused by the duplicate-follow counter bug).

{{/* Rescue stuck posts */}}
Rescue stuck posts

Handles two stuck-post scenarios in one shot: pending_scan > 15 min — re-triggers the content scanner (falls back to clean if unreachable); human_review > 2 h — auto-approves to clean (a human clearly hasn't reviewed them). The background cron also runs this every 10 minutes (with a 4 h threshold for human_review) — use this button to rescue posts immediately.

{{/* Clear orphan video hashes */}}
Clear orphan video hashes

Deletes hash entries from video_raw_hashes that were stored when a video upload started but never linked to a post — because the upload got stuck, timed out, or the browser closed before the user hit Post. Clears entries older than 2 hours with no post_id. Allows the same video to be re-uploaded without hitting the duplicate flag.

{{/* Media fingerprint sweep */}}
Media fingerprint sweep

Indexes all video posts that were never fingerprinted (e.g. uploaded before the scan pipeline was healthy), and fixes attribution for posts sharing the same video file. Processes oldest-first so the original creator is always correctly identified. Safe to re-run — already-indexed posts are skipped.

{{/* Set capability */}}
Set PIAL capability

Grant, revoke, or restrict a platform capability on any PIAL.
