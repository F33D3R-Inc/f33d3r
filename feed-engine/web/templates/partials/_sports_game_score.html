{{/* FACET sports_game_score version: 1.0 | status: stable | layer: 1 (atomic) One side's score. The smallest mutable rendering unit in the sports lane: when a tick moves only the numbers, this is the whole fragment that goes on the wire, and the rest of the card is never re-sent. Before a game starts there is no score. The upstream reports 0–0, which means "nobody has scored yet", not "nil–nil" — so the facet renders an em dash and says so to a screen reader.
